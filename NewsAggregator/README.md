# Агрегатор новостей — вариант 9

Консольное приложение на C# (.NET 8), демонстрирующее паттерны проектирования **Observer** и **Strategy**.

## Возможности

- подписка и отписка пользователей от источников новостей;
- публикация новостей источниками;
- автоматическое уведомление подписчиков при публикации;
- персональная лента пользователя содержит только новости его подписок;
- сортировка ленты по дате, популярности или источнику;
- переключение сортировки во время выполнения.

## Использованные паттерны

### Observer (Наблюдатель)

`INewsSubscriber` задаёт интерфейс получателя уведомлений, `NewsUser` его реализует, а `NewsEventHub` хранит подписки и рассылает опубликованные новости. `NewsSource` обращается к центру событий и не хранит список подписчиков. Благодаря этому источник отделён от конкретных пользователей.

### Strategy (Стратегия)

`INewsSortStrategy` задаёт общий интерфейс сортировки. Его реализуют `SortByDateStrategy`, `SortByPopularityStrategy` и `SortBySourceStrategy`. Класс `NewsFeed` использует выбранную стратегию и может менять её через `SetSortStrategy`, не переписывая сам класс ленты.

## Запуск

Требуется установленный .NET SDK 8. В терминале из папки проекта выполните:

```bash
dotnet restore
dotnet run
```

Можно открыть `NewsAggregator.csproj` в Visual Studio и запустить проект клавишей F5.

## Что проверить при демонстрации

1. У разных пользователей разные подписки и персональные ленты.
2. При публикации новости уведомление получают только подписчики её источника.
3. После отписки пользователь больше не получает новые новости от этого источника.
4. Сортировка ленты переключается по дате, популярности и источнику.
